          Opt-in temperature scaling, applied by cyprid to this model's answers. It never
    changes which answer is chosen, so accuracy is unchanged; a temperature above 1 makes over-confident models
    less extreme. Answers carry x_calibrated and the original numbers in x_raw; a request
    can send "x_calibrate": false to get raw answers.
          
  
          
  
  
          
    
    1 = no change · above 1 = less confident
  
          
  
  
            
  
            Each is fitted and scored on the same run, so it flatters a little. A temperature that
    helps on runs from different suites is the one to trust.
